# @NoticiasES_bot

Web sencilla, hecha solo con HTML y CSS, para presentar **@NoticiasES_bot**: un bot de Telegram que reúne en un solo lugar las noticias de los principales periódicos españoles.

## Qué hace

Cada 5 minutos el bot revisa las noticias de los periódicos. Así no hace falta abrir muchas páginas web: desde Telegram eliges qué quieres leer y ves los titulares al momento.

## Cómo se usa

1. Busca **@NoticiasES_bot** en Telegram y pulsa **Iniciar prueba gratuita**.
2. Escribe **/menu** o pulsa el botón **Menú** abajo a la izquierda.
3. Elige una categoría.
4. Elige un periódico.
5. Elige el periodo: **Hoy**, **Ayer** o **Últimos 7 días**.
6. Lee los titulares y abre los que te interesan.

Además puedes:

- ⭐ **Mis favoritos**: guardar tus periódicos preferidos para encontrarlos más rápido.
- 🔎 **Buscar**: encontrar noticias por palabra.

## Comandos

| Comando | Para qué sirve |
|---|---|
| `/menu` | Abre el menú de noticias |
| `/suscripcion` | Muestra el estado de tu suscripción |
| `/asistenciapagos` | Ayuda con los pagos |

## Precio

Los primeros **7 días son gratis**. Después, la suscripción cuesta **100 Telegram Stars al mes**, es decir, poco más de 2 € al mes: algo más que un café (y si el café es caro, incluso menos).
